# Sons — deux timbres à choisir, consultés le 28/10/2026

> **Lot de sourcing, pas de code.** #379, parent D-137 (a, c). Le module qui les joue est #378 et
> il est **bloqué** par ce lot : rien n'entre dans le dépôt avant que Bastien ait **écouté**.
> Ce dossier ne contient donc **aucun fichier audio** — les assets entreront avec #378.

Deux moments, deux sons, rien de plus : l'**ouverture d'un Arrivage**, et le **verdict** de fin de
combat. Le ton est celui du jeu — **bureau, satire** : du papier qu'on ouvre, un tampon qu'on
frappe, une clochette de machine à écrire. Pas de cartoon, pas de jingle, pas de « ding » de
téléphone.

## 0. Méthode, et ce que le lot ne prouve pas

**Source** : [Freesound](https://freesound.org), filtré **Creative Commons 0** dans la recherche
(`f=license:"Creative Commons 0"`). Aucun autre dépôt n'a été retenu : Wikimedia Commons n'a rendu
que des **prononciations** sur ces requêtes, et les banques d'assets « pack de jeux » (Kenney,
OpenGameArt) sonnent cartoon ou viennent de jeux de cartes existants — les deux exclus par #379.

**Ce qui a été vérifié**, pour chaque candidat, par lecture de sa fiche et par `HEAD` sur le CDN :

1. la **licence** affichée par Freesound est **« Creative Commons 0 »**, avec le texte de la fiche :
   *« You can copy, modify, distribute and perform the sound, even for commercial purposes, all
   without the need of asking permission to the author. »* — CC0 ne demande **aucune
   attribution** ; la provenance est écrite ici quand même, comme le veut le ticket ;
2. le **poids** est la taille réelle du **transcodage `-lq.mp3`** du CDN, mesurée par
   `Content-Length` le 28/10/2026 (voir §3 : c'est ce fichier-là qui entrerait dans le dépôt) ;
3. la **durée**, le **format** et la **date de publication** sont ceux que la fiche affiche.

**Ce qui n'est pas vérifié, et ne sera pas affirmé** :

- **Aucun son n'a été écouté** : le timbre est décrit d'après la **description de l'auteur** et
  ses tags, recopiés ci-dessous. C'est un choix à l'oreille, et il revient à Bastien.
- La licence est celle que **Freesound déclare** sur la fiche, pas un contrat signé : un auteur
  peut s'être trompé. Le seul cas douteux du lot est signalé (§1, candidat **A2**).
- Le poids des fichiers **originaux** (`.wav`) n'est pas retenu : ils exigent un compte pour être
  téléchargés, et ils dépassent largement 100 Ko.

## 3. Ce qui entrerait dans le dépôt, et comment

Rien n'a été téléchargé dans le dépôt (#379 : c'est Bastien qui choisit, les assets entrent avec
#378). Le fichier à récupérer est le **transcodage `-lq.mp3` du CDN**, celui dont le poids est
mesuré ci-dessus — il est **public, sans compte**, et sa licence est la même que celle de la
source (CC0 autorise la redistribution et la modification, le transcodage compris).

Le geste pour #378, quand le choix sera fait :

1. `curl -o public/sons/<nom>.mp3 <URL du CDN>` — les quatre retenus possibles pèsent
   **6 à 51 Ko**, tous sous les 100 Ko du ticket ;
2. **retirer le silence** de début et de fin (fondu de 5–10 ms) : A1 et V3 en ont, à l'oreille
   d'après leur durée ; un son qui colle au silence s'entend plus qu'il ne s'écoute ;
3. écrire la provenance (URL, licence, auteur, date de téléchargement) dans le fichier que #378
   posera — ce README en est la version **avant** choix, il ne remplace pas la provenance des
   fichiers livrés ;
4. vérifier que les fichiers sont **servis** par le bundle (`npm run build`, chemin présent dans
   `dist/`), comme l'exige le critère d'acceptation de #379.

## 4. Licences — pourquoi CC0 convient, et ce qui est exclu

Le jeu est distribué en **MIT** (`LICENSE`), donc **commercialement** : une licence qui
interdirait l'usage commercial, ou exigerait une attribution « dans l'interface », ne passerait
pas. **CC0** est le cas le plus simple — pas d'attribution obligatoire, dérivés permis, usage
commercial permis — et l'attribution est écrite **ici** quand même, parce que le dépôt écrit sa
provenance (même règle que les illustrations).

**Aucune source n'est un jeu de cartes existant**, et rien ne vient des versions abandonnées
(`AGENTS.md` §9) : les six fiches sont des enregistrements de **bureau** déposés par des preneurs
de son, pas des extraits de jeu.
